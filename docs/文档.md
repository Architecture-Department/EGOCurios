# EGOCurios 饰品模组

~50 个 E.G.O. 饰品，15 个 Curios 槽位。

## 槽位

ego_curios, headwear, head, hindbrain, eye, face, cheek, mask, mouth, neck, brooch, hand, glove, left_back, right_back
左右背槽互斥。

## 核心类

- `EgoCurioItem` — 饰品基类，Builder 模式配置四德属性
- `GeoCurioRenderer<T>` — GeckoLib 饰品渲染桥接
- `CurioRegistry` — 15 槽位验证器

## 饰品 Builder

```kotlin
EgoCurioItem.of<EgoCurioItem>()
    .fortitude(2).prudence(3).temperance(0).justice(6)
    .model(EGOCurios.modRl("curios/item_name"))
    .addTooltip("饰品描述")
    .properties(Item.Properties())
```
