# EGOCurios（EGO 饰品）

## 模块定位

管理**EGO 饰品**（Curio/Trinket），使用 Curios API 提供饰品槽位，结合 GeckoLib 进行 3D 渲染。依赖 GoldenBoughsLib 和
ResonatorCombatFramework。

## 项目结构

```
src/main/
├── java/architecture/ego_curios/
│   ├── api/                            — AttackLogicHolder（攻击逻辑持有者接口）
│   ├── common/item/                    — 饰品物品（EgoCurioItem, ComprehensionBackCurioItem, TestEgoCurioItem）
│   ├── core/                           — EGOCuriosConstants
│   │   └── registry/                   — 注册表（Capability, Curio, Payload + 客户端 CurioRenderersRegistrar）
│   ├── datagen/                        — 数据生成（Datagen, CuriosTest, ItemModel, DatapackBuiltin, i18n/ZhCn, BlockTag, ItemTag）
│   ├── events/                         — 事件（LivingEntityEvents, ModEvents）
│   └── util/                           — CurioUtil
│
└── kotlin/architecture/ego_curios/
    ├── client/renderer/                — 饰品渲染器（CuriosRenderer, GeoCurioRenderer, ComprehensionBackCurioRenderer）
    ├── common/payload/toc/             — 网络包（CurioAppurtenanceSynchroPayload, SlotContextExpand）
    ├── core/                           — EGOCurios.kt (@Mod), EGOCuriosClient.kt
    ├── init/                           — 初始化（EGOCuriosItems, EGOCuriosAttachments, EGOCuriosCreativeModeTabs）
    │   └── tag/                        — CuriosItemTags
    └── util/                           — CuriosUtil
```

## 核心类

| 类                                     | 作用          |
|---------------------------------------|-------------|
| `EgoCurioItem`                        | EGO 饰品基础物品类 |
| `ComprehensionBackCurioItem`          | 理解之背（背部饰品）  |
| `AttackLogicHolder`                   | 饰品攻击逻辑接口    |
| `CuriosRenderer` / `GeoCurioRenderer` | 饰品 3D 渲染器   |
| `CurioUtil` / `CuriosUtil`            | 饰品工具方法      |
